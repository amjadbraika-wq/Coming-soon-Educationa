# Coming-soon-Educationa

صفحة "قريباً" لبرنامج تعليمي جديد مع عد تنازلي وتنبيه صوتي.

## الميزات
- ⏳ عد تنازلي لتاريخ 14 أغسطس 2026 - توقيت غزة GMT+3
- 🔊 تنبيه صوتي "وين بابلك وش" عند انتهاء العد
- 🟢 زر الانضمام لمجموعة الواتساب
- 📱 تصميم متجاوب RTL

## الملفات المطلوبة
- `app.py` : كود الموقع
- `requirements.txt` : المكتبات
- `alert.ogg` : ملف الصوت

## النشر على Render
1.  Build Command: `pip install -r requirements.txt`
2.  Start Command: `gunicorn app:app`
